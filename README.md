## The Music Box

https://a4-hawthornwood.onrender.com/

This goal of this project is essentially to be a barebones music maker. The "Make Box" button makes a box with parameters for making sounds. You can make as many boxes as you want. Each box lets you play a specified noise with a specified frequency, filter, and loudness. With this, you can make chords by making 3 boxes each with different frequencies. You can make kick drums by making a sawtooth with a low filter and a 2 or 3 frequency. You can make videogamy noises with the square wave or sub bass with the sine wave. And, if you can type quick enough, you can make a melody by constantly changing the frequency of and playing a box. 

A challenge I faced was making it so that you could make as many audio boxes as you wanted. I just wasn't fully sure how to do it. It made me learn about and how to use classes for javascript so that I could make a list of AudioBox classes which stores them all. Then, I just had to make a bunch of html tags in js which I had to learn how to do a lot of them, which were then linked to the array by number. Another challenge I faced was just getting the analyzer to display in a way thats understandable, and making the functions inside the buttons pass it's number as a parameter. 

The instructions should be clear enough to understand how to use. It's a very simple to understand program.
